# Eight Queens Puzzle

An interactive visualization of the eight queens puzzle. Place eight queens on a standard chessboard so that no two queens share a row, column, or diagonal. Solve it yourself or watch a backtracking algorithm find a solution.

## Features

- Place and remove queens by clicking squares.
- See squares under attack highlighted on the board.
- Prevents placing a queen where it would attack another queen.
- Animate a solution found with backtracking and adjust the animation speed.
- Track the number of queens placed and overall progress.
- Responsive chessboard layout for smaller screens.

## Getting started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL printed by Vite in your browser.

## Build

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
